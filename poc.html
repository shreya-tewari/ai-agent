01 — Overview
✦

Project Overview

The AI Creative Content Agent is a production-ready, full-stack application that takes a single free-form user prompt and autonomously determines what kind of content to create — then generates it using a structured multi-agent pipeline. The result is a unified tool that replaces multiple point solutions (blog writers, caption generators, hashtag tools, script writers) with one intelligent interface.

Problem Statement

Content creators, marketers, and businesses rely on multiple disconnected tools to produce different content formats. This creates context-switching overhead, inconsistent tone/branding, and high subscription costs. A single agent that understands intent and routes intelligently eliminates this fragmentation.

Solution

A LangGraph-orchestrated pipeline with three specialized agents — Planner, Writer, and Reviewer — backed by a FastAPI server and a React/Vite frontend. The system uses LLM-based intent classification so natural phrasing like "make me a reel" correctly routes to the video script generator without rigid keyword matching.

03 — Architecture
🏗

System Architecture

Agent Pipeline (LangGraph)
🧠 Planner
LLM-based intent classification → content_type
▶
✍️ Writer
Selects prompt template, calls Groq LLM
▶
🔍 Reviewer
Polishes grammar & readability (skipped for CAPTION, HASHTAGS)

Planner — Uses the LLM itself to classify intent, so variations like "make me a reel" or "I need a TikTok script" both correctly resolve to VIDEO_SCRIPT. A keyword-based fallback activates if the classification call fails, ensuring zero crashes on API errors.

Writer — Selects the prompt template matching the classified content type and invokes llama-3.3-70b-versatile on Groq at temperature=0.7, max_tokens=4096.

Reviewer — Runs a prose-polish pass on text output. Explicitly skipped for CAPTION and HASHTAGS to prevent corrupting structured JSON or plain hashtag lists.

Key Design Decisions
  • ⚡
    Async execution
    LangGraph's blocking invoke() runs via asyncio.to_thread() so slow generations never stall concurrent requests.
  • 🌊
    Streaming text responses
    Text output is chunked and streamed via StreamingResponse, giving real-time feel without WebSockets.
  • 🛡
    Graceful degradation
    All agents have try/except blocks that preserve previous output instead of losing work on errors.
  • 🔒
    Centralised LLM config
    Single llm_client.py keeps model, temperature, and max_tokens consistent across all agents.
05 — API Reference
📡

API Reference

POST
/generate
Runs the full agent pipeline and returns content. Automatically classifies the content type from the query. Text responses are streamed; caption/hashtag responses are JSON.
Request Body
{
  "query":    "Write a blog about remote work productivity",
  "tone":     "Professional",   // Professional | Creative | Casual
  "length":   "Medium",         // Short | Medium | Long
  "language": "English"         // English | Hindi | Spanish
}
Response Variants
// Text types  →  text/plain stream
// Caption     →  {"type":"caption","caption":"...","hashtags":["#tag1",...]}
// Error       →  {"type":"error","error":"..."}
POST
/followup
Answers a contextual question about previously generated content. The answer is returned as plain text and the frontend appends it inline below the original output.
Request / Response
// Request
{"content":"...generated content...","question":"Suggest some tools?"}

// Response
{"output":"Here are some recommended tools..."}
POST
/refine
Applies a transformation action to existing content. Supported actions: Expand, Rewrite, Improve SEO.
Request / Response
// Request
{"content":"...existing content...","action":"Expand"}

// Response
{"output":"...refined content..."}
